## Generative AI usage

The entire code base of this mod was created with generative AI. Assets are  
free, licensed, paid for, or generated with AI tools. If you do not wish to play  
with AI-generated content, do not install this mod.

## What Y4NGZCore does

Y4NGZCore is a shared library for the Y4NGZ packages. It adds no items, enemies,
UI or gameplay by itself. Your mod manager installs it when a package needs it.
It has no settings of its own.

## Requirements

Your mod manager installs these automatically:

- **BepInExPack**
- **DawnLib**

## Compatibility

Independent installation: Y4NGZCore needs only the libraries listed under
Requirements. These packages require it:

| Mod | What it adds |
| --- | --- |
| **Contracted** | Required. Objective placement. |
| **LethalCCTV** | Required. Camera and stash placement. |
| **Y4NGZ Monitor Takeover** | Required. Ship monitors. |
| **Y4NGZ Ship Systems** | Required. Ship fuel and battery, optional terminal and ship refits. |
| **Y4NGZUI** | Required. Theme and HUD prompts. |
