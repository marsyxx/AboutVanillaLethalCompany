# Chat commands
Mostly for when the game bugs out because of the mod:

### Client commands

Everyone should be able to use these

**!help** - displays a message in the chat, that a player encountered a bug, and needs the host to take care of it (mainly to bypass the proximity restriction, expected response is to use the "!entrance" command)

### Host commands

Only host will be able to use these

**!allowJoin** or **!openLobby** - opens the lobby for invites, useful when disconnecting and reconnecting glitches the lobby into a locked state (seems to happen very often in lobbies bigger than 4 players)

**!return** or **!leave** - makes the ship leave early, useful when disconnecting and reconnecting glitches the amount of players that the game thinks are alive

**!entrance** - use with a player's name to teleport them in front of the main entrance, example: "!entrance McBowie" (it's case specific, so remember to use capital letters where applies) will teleport player named McBowie, useful to counteract a glitch that makes the interior of the building black in some rare cases.
