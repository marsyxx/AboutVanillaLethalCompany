# EladsLethalHUD

Compared to the original mod, this:
- Has improved performance
- Does not hide `Status Effects` from the HUD (such as "Low visibility" warnings, etc.)
- Incorporates some of the tweaks to EladsHUD from [NicheTweaks](https://old.thunderstore.io/c/lethal-company/p/mr_hat/NicheTweaks/), such as:
	- `Fix stamina bar 10% cap` - built in
	- `Trigger health bar popup on heal` - built in
	- `Autohide stamina bar` - configurable
	- `Autohide Oxygen Bar` - configurable
	- `Minimum percentage until popup` - configurable
- Has a built in and configurable oxygen bar
- Stylises the voice activity icon and utility slot, configurable


## Recommended LethalHUD configuration

For the closest match to the original EladsHUD appearance:

```ini
[Custom UI]
Custom Health Bar = EladsHUD Health
Custom Health Bar Color = #FF3636

Custom Stamina Bar = EladsHUD Stamina
Custom Stamina Bar Color = #FF6900

Custom Battery Bar = EladsHUD Battery
Custom Battery Color = #FFFE00


[Health/Stamina/Weight]
Health Size = 21
Health Color = #FFFFFF

Sprint Meter Color = #FF6900

Weight Unit Display = OnlyOne
WeightColor = #FF6900
```
