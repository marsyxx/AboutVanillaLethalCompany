# RTLC Russian Translation Mods
Дополнение к [RTLC Russian Translation](https://thunderstore.io/c/lethal-company/p/Hayrizan/RTLC_Russian_Translation/), которое переводит множество модов на русский язык.

# Ручная установка

1. Скачать архив с локализацией модов и переместить папку 'BepInEx' в корень игры.

# Переведенные модификации

Список переведенных модификаций можно посмотреть в [гугл таблице](https://docs.google.com/spreadsheets/d/1qttPTy8L5fFf9In5t325P6fCTYHJJiTBgCHNNpp3Ums/edit?usp=sharing).

Если вы хотите помочь с переводом проекта (разбираетесь в XUnity.AutoTranslator или программировании), то смело пишите.
