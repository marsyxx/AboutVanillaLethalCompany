# AboutVanillaLethalCompany

Около-ванильная сборка для **Lethal Company**: игра остаётся узнаваемой, а сверху добавлены исправления ошибок, улучшения
производительности, немного нового контента и русская локализация. Плюс три собственных мода команды **devil1nme**
(графика + DLSS, переключатель языка, исправления совместимости).

* Игра: сборка от 31 октября 2026 (в меню отображается v81), Unity 2022.3.62f2, Direct3D 11.
* Загрузчик: BepInEx 5.4.2305.
* Модов в сборке: **96** (полный список с версиями и ссылками на Thunderstore — [modpack/MODS.md](modpack/MODS.md)).
* Для DLSS нужна видеокарта NVIDIA RTX (у остальных строка DLSS в настройках просто не показывается).

## Установка

1. Установи **Thunderstore Mod Manager** или **r2modman**, создай профиль для Lethal Company.
2. Импортируй профиль из файла `modpack/AboutVanillaLethalCompany.r2x`
   (Settings → Profiles → Import / Update → From file). Менеджер сам скачает все моды из списка.
   Если менеджер файл не принял, поставь моды по [modpack/MODS.md](modpack/MODS.md) вручную.
3. Из [Releases](../../releases) скачай три архива `devil1nme-GraphicsPlus`, `devil1nme-LanguageSwitch`,
   `devil1nme-LCCompatFixes` и поставь их через **Import local mod** (они ещё не опубликованы на Thunderstore).
4. Скопируй содержимое `modpack/config` в папку профиля `BepInEx/config` (с заменой файлов).
5. Запусти игру через менеджер. Язык меняется в **Настройки → Язык** (между блоками «Управление» и Graphics),
   графика — кнопка **Graphics+** внизу блока Graphics.

Профиль `.r2x` создан из экспорта нашего профиля, но импорт на чистой установке я не проверял. Если что-то не сошлось,
ориентируйся на MODS.md.

## Наши моды

| Мод | Что делает |
|---|---|
| **GraphicsPlus** | Страница расширенных настроек графики внутри экрана настроек игры: разрешение рендера, **DLSS**, сглаживание (FXAA / SMAA / TAA), тени, текстуры, затенение углов, эффекты. По умолчанию всё как в игре; пока используется Graphics+, родные пункты Graphics заблокированы. |
| **LanguageSwitch** | Выбор языка (English / Русский / Deutsch) выпадающим списком в основных настройках, применяется сразу. Содержит немецкий словарь. В русском и немецком меню пункты главного меню не заходят на лого. |
| **LCCompatFixes** | Исправления чужих модов без правки их файлов: LethalCasino и звуковые паки RTLC после обновления игры, вылет EladsHUD+, фриз 1–2 с при посадке из-за RTLC, повторные медленные сканы и поиски типов HarmonyX (половина «мёртвого» времени при запуске), порядок патчей LethalRPG Strength и BetterStamina. У каждого исправления есть переключатель в конфиге. |

Подробности: [docs/OUR-MODS.md](docs/OUR-MODS.md). Сборка: `powershell -ExecutionPolicy Bypass -File tools\build.ps1`.

## Что измерено

Замеры делались в офлайн-лобби на Experimentation на этом наборе модов:

* **Запуск до главного меню** (холодный старт, вход в офлайн-LAN автоматически, замер зондом `tools/dev/StartupProbe` без сэмплера; один прогон «до», два «после»):

  | | до | после |
  |---|---|---|
  | главное меню появилось на | 78 с | 55–56 с |
  | сумма кадров дольше 0,2 с до +30 с после меню («зависания») | 53 с | 22 с |
  | зависаний дольше 1 с | 9 | 5 |
  | самый долгий кадр | 12 с | 8–12 с |

  Главная причина: `AccessTools.TypeByName` из HarmonyX при поиске типа, которого нет (модов-«необязательных зависимостей» много),
  заново собирает полное имя у ~100 тысяч типов, дважды; на каждый промах 2–6 с. Так делали LazyLobby, LazyLanding и
  WeatherRegistry. Исправление `FastTypeByName` в LCCompatFixes 1.0.1 даёт тот же тип, но промахи отвечаются сразу.
  Ещё около 8% отъедали наши `InjectAll` (поиск панели настроек по всем объектам в памяти): исправлено в GraphicsPlus и LanguageSwitch 1.0.1.
* Кадр в **2,1 с** при загрузке уровня (проход RTLC по всем текстурам) убран: теперь работа идёт по 3 мс за кадр.
* Падающих сканов типов HarmonyX за сессию: **132 → 7**; запуск примерно на 4 с быстрее.
* Сборка мусора (GC) на лаги при посадке не влияет: во всех кадрах дольше 100 мс сборок не было.
* Остаются отдельные кадры по 100–320 мс при загрузке сцены и генерации интерьера (игра и другие моды).

## Известные проблемы

* **DawnLib и Configurable Company Variables (LCV)** конфликтуют на `RoundManager.PredictAllOutsideEnemies`: патч DawnLib не
  применяется (в логе `Failed to apply RoundManager.PredictAllOutsideEnemies patch (1)`). Последствие: вероятности внешних
  врагов от DawnLib не используются в предсказании.
* DawnLib не может сопоставить IL в `PlayerControllerB.DestroyItemInSlot` (`Couldn't match ... (4) IL`): этот метод уже
  переписывает мод `JacobG5.DestroyItemInSlotFix`. Один из двух патчей не применяется; какой важнее, решай по сборке.
* В первом кадре после загрузки плагинов LethalLevelLoader инициализирует все пакеты с контентом лун: 5–12 секунд без картинки.
  Это его собственная работа (читает все ассеты `ExtendedMod`), обойти без правки мода нельзя.
* Configurable Company строит меню из ~3500 настроек порциями по 24 мс на кадр: около 23 с сниженного FPS в главном меню
  (в логе строки `Configuration loading took more than 2500ms` — это только отметки прогресса, не зависания).
* Ошибки Newtonsoft `AotHelper` в логе безвредны: их дают облачные службы Unity, которые игра не использует.
* Немецкий перевод написан с помощью ИИ и не проверен носителем языка.
