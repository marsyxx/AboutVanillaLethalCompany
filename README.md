# AboutVanillaLethalCompany

Готовая сборка **Lethal Company** для друзей: игра остаётся узнаваемой, а сверху добавлены исправления ошибок, ускорение загрузки,
немного нового контента, русская локализация и три собственных мода команды **devil1nme** (графика с DLSS, переключатель языка,
исправления совместимости). Ставится копированием файлов в папку игры, менеджер модов не нужен.

* Игра: Steam-версия, сборка от 31 октября 2026 (в меню отображается **v81**). На другой сборке игры часть модов может не работать.
* Windows 10/11, 64-бит. Для DLSS нужна видеокарта NVIDIA RTX (у остальных строка DLSS в настройках просто не показывается).
* Места: около 1 ГБ сама сборка и до 3 ГБ кеша, который мод ускорения загрузки сам создаёт в папке игры (`Cache`).
* Состав: [MODS.md](MODS.md) (99 пакетов: часть из них библиотеки; при запуске грузится около 90 плагинов).

## Установка

1. Установи Lethal Company через Steam.
2. Скачай сборку: на странице репозитория **Code → Download ZIP** (около 1 ГБ) и распакуй архив.
3. Открой папку игры: Steam → Lethal Company → правая кнопка → **Управление → Просмотреть локальные файлы** (там лежит `Lethal Company.exe`).
4. Скопируй в эту папку **содержимое** распакованной папки, соглашаясь на замену:
   * папки `BepInEx` и `_state`
   * файлы `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version` (точка в начале имени: включи показ скрытых файлов)
   * `mods.yml` (список установленных модов, как в менеджере модов; на работу игры не влияет)

   Остальные файлы из архива (`README.md`, `MODS.md`, `CHANGELOG.md`, `.gitignore`, `.gitattributes`) копировать не обязательно.
5. Запускай игру из Steam как обычно.

Steam Deck и Linux: в параметры запуска игры добавь `WINEDLLOVERRIDES="winhttp=n,b" %command%`.

**Первый запуск долгий**: около 2–3 минут до главного меню, пока мод ускорения загрузки распаковывает ресурсы в папку `Cache`, а наш
патчер склеивает большой файл LethalCasino (на GitHub он хранится двумя частями, потому что файлы больше 100 МБ не принимаются).
Следующие запуски быстрее (на моём компьютере главное меню появляется примерно через минуту). Не закрывай окно, пока оно не ответит.

## Игра вдвоём и в компании

Все участники лобби должны поставить **одну и ту же версию сборки** (см. [CHANGELOG.md](CHANGELOG.md)): иначе игра покажет несовпадение
модов или будет ошибаться при загрузке.

## Настройки

* **Язык**: Настройки → выпадающий список «Язык» между блоками «Управление» и Graphics (English / Русский / Deutsch, применяется сразу).
  По умолчанию русский.
* **Графика**: Настройки → блок Graphics → кнопка **Graphics+**: разрешение рендера, DLSS, сглаживание, тени, текстуры, эффекты.
  Пока используются настройки Graphics+, родные пункты Graphics заблокированы (отключается в самой странице Graphics+).
* Остальные настройки модов: меню модов LethalConfig (кнопка на главном экране) и файлы в `BepInEx/config`.

## Обновление

Новая версия сборки выкладывается в этот репозиторий. Чтобы обновиться, удали в папке игры `BepInEx\plugins`, `BepInEx\patchers`
и `BepInEx\core`, потом скопируй всё заново, как при установке. Так не останется файлов модов, которых в новой версии уже нет.
Папку `BepInEx\config` перезапись тоже: твои личные изменения в настройках модов пропадут, сохрани их заранее, если они важны.

## Удаление

Удали из папки игры `BepInEx`, `_state`, `Cache`, `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version`, `mods.yml`. Чтобы лишь на время играть без модов,
достаточно переименовать `winhttp.dll`.

## Что мы добавили к чужим модам

| Наш мод | Что делает |
|---|---|
| **GraphicsPlus** | Страница расширенных настроек графики в экране настроек игры и в меню паузы: разрешение рендера, **DLSS**, сглаживание (FXAA / SMAA / TAA), тени, текстуры, затенение углов, эффекты. По умолчанию всё как в игре. |
| **LanguageSwitch** | Выбор языка (English / Русский / Deutsch) в основных настройках, применяется сразу; немецкий словарь; в русском и немецком меню пункты не заходят на лого. |
| **LCCompatFixes** | Исправления чужих модов без правки их файлов: LethalCasino и звуковые паки RTLC после обновления игры, вылет EladsHUD+, фриз 1–2 с при посадке из-за RTLC, медленные поиски типов HarmonyX (половина «мёртвого» времени запуска), порядок патчей LethalRPG Strength и BetterStamina, склейка файлов, разрезанных для GitHub. У каждого исправления есть переключатель в `BepInEx/config/lc.compatfixes.cfg`. |

Исходный код наших модов пока лежит у автора локально; позже он переедет в отдельные репозитории.

## Что измерено

Запуск до главного меню (холодный запуск, замер зондом без вмешательства в игру, моя машина; ускорение `FastTypeByName`):

| | до | после |
|---|---|---|
| главное меню появилось на | 78 с | 55–56 с |
| сумма кадров дольше 0,2 с («зависания») до +30 с после меню | 53 с | 22 с |
| самый долгий кадр | 12 с | 8–12 с |

Главная причина была в `AccessTools.TypeByName` из HarmonyX: поиск несуществующего типа (а необязательных модов у нас много) стоил 2–6 с,
и его делали LazyLobby, LazyLanding и WeatherRegistry. Остаются отдельные кадры по 100–320 мс при посадке на планету.

## Известные проблемы

Список открытых задач: [Issues](../../issues). Главное:

* **DawnLib и Configurable Company Variables (LCV)** конфликтуют на `RoundManager.PredictAllOutsideEnemies`: вероятности внешних
  врагов от DawnLib не используются в предсказании ([#9](../../issues/9)).
* **DawnLib и `JacobG5.DestroyItemInSlotFix`** оба переписывают `PlayerControllerB.DestroyItemInSlot`, один из патчей не применяется ([#10](../../issues/10)).
* В первом кадре после загрузки плагинов LethalLevelLoader инициализирует пакеты с контентом лун: 5–12 секунд без картинки ([#17](../../issues/17)).
* Configurable Company строит меню из ~3500 настроек порциями по 24 мс на кадр: около 23 с сниженного FPS в главном меню ([#5](../../issues/5)).
* Немецкий перевод написан с помощью ИИ и не проверен носителем языка ([#12](../../issues/12)).
* Ошибки Newtonsoft `AotHelper` в логе безвредны: их дают облачные службы Unity, которые игра не использует.

Если что-то не работает, пришли файл `BepInEx/LogOutput.log` в [Issues](../../issues/new). Если игра лагает, приложи ещё `BepInEx/perf-summary.txt`: там FPS и память по местам (меню, корабль, планета). Файл создаётся только у тебя на компьютере, личных данных в нём нет.

## Лицензии и авторы

Файлы в `BepInEx/plugins` принадлежат их авторам и распространяются по их лицензиям; страницы модов и авторов указаны в
[MODS.md](MODS.md). Сборка собрана из профиля Thunderstore Mod Manager и выложена для друзей. Если автор мода против такого
распространения, напишите в [Issues](../../issues/new): мод будет убран. Наши моды: MIT, разработаны командой devil1nme при помощи ИИ (Claude).
