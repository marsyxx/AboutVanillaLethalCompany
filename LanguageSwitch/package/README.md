# LanguageSwitch

Choose the language of Lethal Company in the game's own **Settings** screen: **English**, **Russian** or **German**.
The change applies live, without restarting the game, and is remembered for the next launch.

The text itself is displayed by [XUnity.AutoTranslator](https://github.com/bbepis/XUnity.AutoTranslator), the engine the
RTLC Russian translation is built on. LanguageSwitch only drives it, so it works together with the RTLC Russian
translation packs.

## Where to find it

Main menu or pause menu -> **Settings** -> the **Language** dropdown between the *Controls* and *Graphics* boxes. The change applies at once. In Russian and German the main-menu items are also set slightly tighter so they stay clear of the logo.

## How each language works

| Language | Source of the text | Notes |
|---|---|---|
| English | the game's original text and logo | Translation is switched off and everything already translated is put back. |
| Russian | the RTLC Russian translation (static, offline) | Needs the RTLC Russian translation mods installed; the game's Russian logo is restored too. |
| German | a German dictionary **included in this package** (about 670 entries for the game's own text) | Offline. Covers menus, settings, HUD and prompts, item names, creatures, locations, scan nodes and the terminal's fixed texts. |

**Honest limits**

* The German text was written with AI assistance from the English game strings and has **not** been reviewed by a native
  speaker. Fixes are welcome: edit `BepInEx/config/Translation_de/Game/*.txt` (format `original=translation`).
* Text that is **not** in the dictionary stays English. This includes text added by other mods, long terminal
  pages, the long Russian-specific regular-expression texts RTLC has (casualty reports etc.) and anything generated by the game
  at runtime in an unusual format. Online machine translation is not used: in testing, XUnity's Google endpoint did not
  return any translations.
* Voice and sound replacements that other mods provide (for example the Russian ship announcer from the RTLC sound
  packs) are not controlled by this mod.
* Some text updates the next time its menu or scene is opened. Long German words can be wider than the original English in a few UI boxes.

## Requirements

* [RTLC-XUnity_AutoTranslator](https://thunderstore.io/c/lethal-company/p/RTLC/XUnity_AutoTranslator/) (installed automatically).
  The older `Hayrizan-XUnity_AutoTranslator` package contains the same plugin and also works.
* If XUnity is missing or disabled, LanguageSwitch logs a warning and does nothing; the game is unaffected.

## First launch

If you have never picked a language, nothing is changed: XUnity keeps the language it was already configured for.
After you choose one, it is stored in `BepInEx/config/lc.languageswitch.cfg`.

## Reporting problems

Please attach `BepInEx/LogOutput.log` (look for lines starting with `[LanguageSwitch]`).
